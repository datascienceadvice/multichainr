# Print MultiChain help

S3 method for printing objects returned by
[`mc_help`](https://datascienceadvice.github.io/multichainr/reference/mc_help.md).
Displays the help text in a clean format.

## Usage

``` r
# S3 method for class 'mc_help'
print(x, ...)
```

## Arguments

- x:

  An object of class `"mc_help"`.

- ...:

  Additional arguments (ignored).

## Value

Invisibly returns `x`.
